# BIKE LAB — 精密自行车实验室

单文件 3D 公路车实验室，用于观察机械结构、交互拆装和传动原理学习。原生 HTML / CSS / JavaScript，Three.js **0.180.0**，全部自行车几何由程序生成。

## 运行

在项目目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。无需 npm 依赖或构建；需要支持 WebGL 2 的现代浏览器，以及可访问 jsDelivr 的网络。不要直接双击 HTML；端口占用时可更换端口。

## 功能与操作

| 功能 | 当前实现 |
| --- | --- |
| 程序化公路车 | 变截面气动车架、碳纤维材质、弯把、坐垫、700C 轮组、交叉辐条、160 mm 碟刹、双牙盘、12 片飞轮、双导轮后拨、前拨及真实链节 |
| 34 个逻辑组件 | 编号、中英文名称、材料、原理、演示规格、装配坐标和连接关系；支持搜索、分类筛选和目录折叠 |
| 零件探索 | 悬停、点击、双击聚焦、关联高亮、隔离、隐藏和恢复；目录、详情与模型同步 |
| 拆装 | 单件、当前系统、全车拆装和连续进度；支持动画暂停、继续及中途反向，拆解沿安装轴展开 |
| 传动 | 50 / 34T 前盘、11–34T 的 12 档后飞轮、30–120 RPM 踏频、0.25 / 0.5 / 1 / 2× 演示速度；前轮不受驱动，脚踏保持水平 |
| 花鼓声音 | 原生 Web Audio 合成棘轮声，节奏随后轮转速和演示倍率变化；0–100% 音量，默认 40%，0% 静音 |
| 三种模式 | 产品展示使用整幅场景；工程标注显示目录、属性和拆解控制；机械传动突出传动特写与实验控制。共用同一模型，可独立叠加透视观察 |
| 工程标注 | 整车默认最多 6 个核心标注；目录系统筛选同步突出对应零件和连接关系，手机最多 5 个、较宽视口最多 8 个系统标签；拆解强调移动件、安装轴和装配原位 |
| 机械导学 | 8 章、12 个画面，每步配一个操作与结果说明；包含关联高亮、透视、隔离轴承、拆碟片、启动、聚焦和换挡；自动导学等待操作完成后再推进 |
| 传动解释 | 调整前后齿数或踏频后，说明改变原因及前后转速；暂停时区分名义转速与仪表的 0 RPM |
| 产品巡航 | 缓慢环绕，每 10 秒切换全景 / 传动 / 车架 / 碟刹镜头；拖动相机立即接管 |
| 显示设置 | 网格、外壳不透明度、柔和光晕、LOW / MEDIUM / HIGH 画质、全屏；支持平板侧抽屉和手机底部详情 |

- **左键 / 单指拖动**旋转，**滚轮 / 双指捏合**缩放，**右键拖动**平移。
- 点击模型或目录选择组件，双击模型聚焦；点击空白处或“返回产品档案”取消选择。
- 产品模式通过“组件目录 / 产品档案”打开面板，点击“进入工程探索”展开完整工作区；桌面直接点选模型时打开零件检查器。
- 在详情中操作单件，在工程模式底部控制台操作当前系统或整车。产品模式拆解单件时自动进入工程模式；一体成型车架的六个结构保持完整，不作为可维修拆卸件。
- 拆解立即暂停传动；只有全部组装完成，才能启动传动或换挡。踏频设置保留。
- 点击“开始传动”后播放模拟花鼓声，在底部“花鼓音量”调节响度。暂停、拆解或切换到后台时静音；页面首次打开不自动发声。
- 透视滑块调节的是**外壳不透明度**：数值越低，内部结构越清楚。
- 工程模式的目录系统下拉框同时筛选标注与关系线；选择零件自动展开其系统。选择“全部机械系统”或取消选择回到整车核心标注。“当前系统”支持直接拆装所筛选的系统。
- 导学默认使用 60 RPM、0.25× 慢放，变速章节固定以 50 / 17T、80 RPM 开始。点击章节操作按钮，或在传动控制区完成相同换挡操作，显示结果与原因。
- 自动导学会等待当前操作完成，再停留 6 秒进入下一步；也可手动翻页。翻页和退出会复装教学拆解件、取消隔离；退出时恢复进入前的齿数、踏频、演示速度及透视开关。
- 手机导学内容可以滚动，顶部关闭按钮始终可见；面板上方的模型仍可拖动观察。
- 1100px 及以下使用目录 / 详情抽屉；手机仅展开当前模式需要的控制区，主要按钮和档位控件至少 44px 高。窄屏特写按场景比例取景，减少链条与飞轮被裁切。

| 快捷键 | 操作 |
| --- | --- |
| `R` / `F` | 视角复位 / 聚焦选中零件 |
| `E` / `Q` | 进入工程模式并全部拆解 / 全部组装 |
| `Space` | 进入机械模式并启停传动；导学中控制当前演示 |
| `H` / `X` | 隐藏选中零件 / 透视开关 |
| `1` / `2` / `3` | 产品 / 工程 / 机械模式 |
| `Esc` | 退出导学、隔离和透视，关闭抽屉并回到产品模式 |

输入框、下拉框或帮助弹窗内不触发全局快捷键；按钮上的空格保留原生操作。

## 仿真约定

模型轮径 700 mm、轴距 1020 mm、曲柄 172.5 mm；链条固定 **108 节、12.7 mm 节距**。界面规格与仪表数据均为演示数据。

```text
曲柄角速度 = 踏频 × 2π / 60
后轮角速度 = 曲柄角速度 × 前盘齿数 / 后齿片齿数
平均链速 = 曲柄角速度 × 前盘齿数 × 链条节距 / (2π)
模拟速度 km/h = 后轮 RPM × π × 轮径 m × 60 / 1000
```

后拨姿态由链路闭合约束求解，换挡不增删链节。仪表显示设定踏频下的名义运动学数据；慢放倍率控制仿真时间推进，不改变名义传动比。

- `index.html`：完整运行文件，部署时只需要它。
- [技术实现与边界](docs/EXTENSIONS.md)：坐标、状态、链条、渲染及资源管理。

## 适用范围

这是结构展示和运动学教学模型，规格不对应某款商品的测量数据，不提供加工公差、维修顺序保证或 CAD 导出。未模拟真实换挡瞬态、弹性、摩擦、负载、制动动力学或自由轮滑行。

材质使用 PBR、环境反射、接触阴影与可选 Bloom；没有光线追踪、屏幕空间反射或独立 SSAO。遇到性能限制可选 LOW 或关闭光晕，此时直接渲染场景。字体使用系统回退，Three.js 仍需联网加载，未提供离线引擎包。

移动端检查使用 Chromium 尺寸与触摸仿真；未在实体手机、Safari 或 Firefox 上验收。性能数值仅代表记录中的本机短时采样。
