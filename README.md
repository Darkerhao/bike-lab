# BIKE LAB — 智能自行车实验室

单文件、实时交互的 3D 公路车实验室。使用原生 HTML、CSS、JavaScript 和 Three.js 0.180.0；自行车全部由程序化几何体生成。

## 运行

在项目目录打开终端：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

然后访问 **http://127.0.0.1:8080/**。

无需 npm、安装项目依赖或构建。需要联网加载 jsDelivr 上的 Three.js，以及支持 WebGL 2 的现代浏览器。请通过 HTTP 服务运行，不要直接双击 `index.html`。如果端口已占用，可将命令中的端口改为 `8081`，并访问相应地址。

## 操作

- **左键拖动 / 单指拖动**：旋转；**滚轮 / 双指捏合**：缩放；**右键拖动**：平移。
- 点击模型或组件目录选择零件；双击模型聚焦；点击空白处取消选择。
- 在详情中拆装单个零件，或使用底部进度条连续拆解整车。
- 工程模式下点击编号查看组件；“关联零件”同时高亮并连接相关组件。
- 透视滑块控制的是**不透明度**：数值越小，越容易看见内部结构。
- 教学默认每步停留 5 秒，动画速度选择会同时调整教学节奏。
- `Space`：传动启停；`R`：视角复位；`Esc`：取消选择、关闭抽屉。输入框、按钮和弹窗保留原生键盘行为。
- 手机和平板通过场景上的“组件目录”“零件详情”打开面板。

## 仿真约定

内部单位为米、秒和弧度，采用 Three.js 的 **Y 向上**坐标系。牙盘为 50T，飞轮为 11–34T，轮径约 700 mm，轴距 1120 mm。

```text
曲柄角速度 = 踏频 × 2π / 60
后轮角速度 = 曲柄角速度 × 50 / 后飞轮齿数
链条线速度 = 曲柄角速度 × 牙盘节圆半径
模拟速度 km/h = 后轮 RPM × π × 轮径 m × 60 / 1000
```

链条使用解析切线和圆弧构成闭合路径，分别实例化链板、滚子和链销。左右曲柄相差 180°；脚踏随曲柄公转并保持踏面水平。

## 实现与文件

```text
index.html            全部运行时代码、样式、场景和模型
README.md             运行说明、功能与限制
docs/TASK.md          用户提供的完整原始任务
docs/EXTENSIONS.md    三种新增模式及实现约定
docs/VERIFICATION.md  浏览器验收记录
```

`index.html` 按数据、几何辅助函数、模型生成、零件管理、拆解、传动、相机、教学、工程标注、UI、交互与应用生命周期划分。使用一个零件注册表与一个动画循环；所有拆解位置都从原始位置计算。

Three.js 核心与 addons 均固定到 `0.180.0`，通过同一份 importmap 加载。高重复几何使用 InstancedMesh；材质按组件与外壳属性复用；支持限制像素比、画质切换、尺寸观察和退出释放资源。

## 验证与限制

已在 Chromium 浏览器中完成实际渲染、传动比例、独立拆装、连续拆解、工程与透视模式、完整教学流程、鼠标交互、全屏和响应式检查。手机触摸通过浏览器触摸事件仿真验证，**未在实体手机或 Safari/Firefox 上验收**。详细记录见 [浏览器验收](docs/VERIFICATION.md)。

- 这是结构展示与运动学教学模型，不是可加工的 CAD，也不是具体商品的测量数据。零件规格均标明为演示数据。
- 换挡立即切换工作齿片与链条路径，不模拟实际拨链过渡、负载、摩擦、惯性、刹车动力学和链条弹性。
- 链条闭合时采用偶数链节并微调可视间距；换挡会重采样链条，不模拟真实车辆中固定链长与后拨弹簧的张力求解。
- 拆解距离为教学展示间距。轮组内部、成对零件和最终碳纤维管件的展开用于理解结构；一体碳纤维车架不能在维修中拆成管件。
- 透视使用半透明外壳，工程标注使用参考尺寸；不提供剖切平面、加工公差或 CAD 导出。
- 灯光使用环境反射、接触阴影和适度 Bloom；不进行光线追踪、屏幕空间反射或独立 SSAO。低性能设备可关闭光晕并选择“流畅”画质。
- 页面需要访问 CDN；没有将 Three.js 打包为离线依赖。
