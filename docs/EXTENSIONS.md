# BIKE LAB 技术实现与边界

本文件按当前 `index.html` 说明实现；本轮需求以 [TASK2](TASK2.md) 为准。早期单牙盘、33 组件和拆卸顺序教学的说明已被当前实现替代。

## 数据与坐标

- `CONFIG` 统一尺寸、基准点、前后齿数、链条节距和固定链数。
- 机械坐标为 X 向前、Y 向左、Z 向上；通过 `toScene([X,Y,Z]) → (X,Z,-Y)` 映射到 Three.js 的 Y 向上坐标。界面坐标再映射回机械坐标，单位 mm。
- `BIKE_DATA` 提供 34 个组件的语义信息。`ComponentManager` 注册唯一 Group，并给所有子 Mesh 绑定同一零件 ID；Raycaster 的交点回溯到该 ID。
- 注册表保存装配位置、四元数、缩放、拆解目标和左右分体原始变换。个人隐藏状态存于组件，隔离对象只存一个 ID，最终显示状态统一派生。

## 几何与材质

车架使用变截面扫掠；弯把和走线使用曲线；坐垫采用轮廓曲面。牙盘、飞轮和碟片由带孔形状及齿形生成，轮组采用交叉辐条，链板、链销、滚子与重复细节使用实例化几何。

碳纤维及胎纹来自 CanvasTexture，金属、清漆、橡胶和软质材料使用不同 PBR 参数。选中和透视不覆盖基准颜色；材质按组件和外壳标记复用，透明外壳不写入深度，内部轴承保持实体显示。

2026-11-15 调整：碳纤维与涂装采用非金属基础层和清漆反射；轮胎通过高粗糙度与较低镜面强度保持哑光；铝 / 钢件通过粗糙度和各向异性区分。沿用现有环境、主辅轮廓光和接触阴影，不新增后处理通道或外部资源。

## 拆解与状态

`EXPLODE` 是唯一安装轴配置。`ExplodeController` 的单件、系统、全部、滑块操作共用绝对插值；反复操作不累计位移。一体成型碳纤维的六个结构不可拆，其余部件沿安装方向展开。拆解间距服务于观察，不代表实际维修工具空间。

开始拆解时暂停传动并恢复机械运动姿态；装配判断同时检查当前位置和动画目标，避免动画未完成时错误放行。相机、拆装、教学、传动在一个 RAF 中更新，页面隐藏时暂停传动和自动讲解。

## 传动链路

输入为曲柄角速度。牙盘与曲柄刚性联动，后飞轮 / 后花鼓壳体 / 后轮使用前后齿数比；贯通轴不随轮组旋转，前轮不受驱动，脚踏反向补偿公转角度以保持踏面水平。

链路采用前后齿盘、上下导轮的圆弧与切线。每节长度固定为 12.7 mm，直线和圆弧内部使用解析弦长，跨切点使用标量求根；后拨导板角度由 108 节闭合约束求解。链板按三维切向定姿，换挡改变链线和后拨姿态，不伸缩或增删链节。

运动使用齿数比的理想平均角速度；链速按每转送出的链长计算。离散链条的几何节圆半径为 `pitch / (2 sin(π / teeth))`，不把它与平均链速半径混用。求解不包含真实受力、齿间碰撞、链条多边形效应造成的瞬时速度波动或自由轮行为。

花鼓声由原生 Web Audio 合成，一段循环缓冲表示后轮一转的 36 次短促棘轮声。播放倍率使用后轮名义 RPM × 演示倍率，响度由唯一的 `state.hubVolume` 控制；复用一个 AudioContext、循环音源和增益节点，不添加音频文件或依赖。用户首次操作传动、导学或音量时初始化音频，静止时增益为零，场景销毁时关闭音频上下文。声音是配合传动的听觉演示，不表示真实花鼓在踩踏时发生棘轮滑动，也未增加自由轮滑行仿真。

## UI 与教学

三模式共用原模型。透视、选择、隐藏、隔离与拆解各自有单一状态，按钮从当前状态派生。事件绑定限定为 `button[data-mode]`，不会匹配用于样式的 body 属性。

布局由 `state.mode`、`state.guided` 与 1100px 断点派生：产品模式收起目录和控制台；工程模式保留目录、检查器和拆解；机械 / 导学集中展示传动控制。`UIController.syncLayout` 统一计算面板停靠、drawer 类、入口和 inert，不另存布局状态。产品模式单件拆解及全局快捷键进入对应工作区；切回产品模式时暂停传动，防止控制台隐藏后继续播放。

工程标注与目录共用 `category-filter`，不新增系统筛选状态。整车使用六个系统的核心零件，较宽视口最多 6 个标签，手机最多 5 个；系统筛选后显示对应零件和系统内部关系线，选中件还显示跨系统直接连接，系统标签较宽视口最多 8 个、手机最多 5 个。标签优先选中件和移动件，避让控件及其他标签；参考尺寸出界时隐藏。

拆解移动由零件当前进度与目标进度之差派生，不增加运动状态。移动件使用暖色高亮；仅移动件或已展开选中件显示安装轴与原位亮点，继续使用现有虚线连接装配位置。

教学共 8 章、12 个画面，每步声明操作、目标及结论，调用既有选择、隔离、透视、拆解、镜头和传动控制器。完成条件读取真实场景状态，完成后保存本步结论；翻页统一复装并恢复整车，再设置新章节参数。自动导学等待操作完成后停留 6 秒，与拆装动画速度独立。进入前保存齿数、踏频、慢放倍率及透视开关；退出时恢复，教学隔离和拆解不遗留。

完成判定只更新当前按钮和结论，自动导学启停及后台暂停只更新播放控件，以保留滚动位置与当前节点。切章时重建章节内容并回到顶部。

传动说明共用现有名义转速公式。用户改变踏频或齿数时记录该次前后参数用于对比，参数由其他流程重设后清除旧比较。暂停时明确区分设定关系与零转速仪表；慢放不改变名义传动比。导学换挡结论复用同一个说明函数。

平板侧边抽屉、手机底部详情使用同一 DOM。关闭抽屉同时设为不可见和 inert；详情标题栏固定在滚动容器顶部，切章回到顶部；导学详情打开时不使用遮罩阻断模型拖动。

主要说明使用 13–14px 字号，手机关键按钮和档位控件至少 44px 高。手机工程 / 机械模式省略重复产品标题，导学进一步收起辅助工具入口。近景镜头在窄屏按相机比例调整距离，导学和自由观察使用各自的画面中心位置。

## 渲染与生命周期

Three.js 核心和所有 addons 固定为 **0.180.0**。使用 ACES 色调映射、sRGB 输出、RoomEnvironment 环境反射及多光源。开启光晕时使用 EffectComposer / Bloom / OutputPass；关闭光晕或选择 LOW 时直接调用 renderer.render，保留渲染器自身的色调映射与颜色空间转换。

| 画质 | DPR 上限 | 动态阴影 | Bloom |
| --- | --- | --- | --- |
| LOW | 1 | 关闭 | 关闭 |
| MEDIUM | 1.5 | 1024 | 由光晕开关控制 |
| HIGH | 2 | 2048 | 由光晕开关控制 |

窗口 resize 事件与模式 / 导学事件同步布局，ResizeObserver 仅同步相机、渲染器和后处理尺寸，视口比例明显变化时重新构图。布局同步不依赖画布非零尺寸，也不在 ResizeObserver 中修改被观察布局，避免断点切换死锁及 observer 循环。页面退出移除窗口监听并统一释放几何、材质、纹理、控制器和后处理资源；上下文丢失时显示重载入口。

应用无业务后端或持久化设置，不引入构建工具。`window.bikeLab` 仅暴露只读诊断，供验收检查真实场景状态，不驱动应用行为。

本轮渲染优化核对了 [r180 OutputPass 源码](https://github.com/mrdoob/three.js/blob/r180/examples/jsm/postprocessing/OutputPass.js)、[WebGLRenderer 源码](https://github.com/mrdoob/three.js/blob/r180/src/renderers/WebGLRenderer.js)及其同版本 API 文档，下载参考保存在 `artifacts/references/`。
