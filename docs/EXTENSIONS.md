# BIKE LAB 增补需求与实现约定

本文件补充用户原始任务（见 TASK.md），与原始任务共同作为验收依据。

## 三种观察与学习模式

1. **工程标注**：所有可交互组件自动编号；显示组件间装配连接、原始安装位置、拆装方向及轴距和轮径参考尺寸。标签与目录双向选取。尺寸为程序模型参考值，不是加工图纸。
2. **透视观察**：车架、前叉、轮毂和五通外壳半透明，透明度连续可调；保留轴心、轴承滚珠和塔基的实体显示。
3. **拆解教学**：按卸载传动、制动、车轮、接触点、转向、车架的顺序分步讲解；自动聚焦、上一步、下一步、自动播放；完成后显示完整爆炸图。真实维护依车辆厂商手册执行，演示不替代维修指导。

## 实现范围

- 原生 HTML / CSS / JavaScript，Three.js **0.180.0** 及同版本 addons，通过 importmap 从 jsDelivr 加载。
- 全部运行时代码位于根目录 `index.html`；不安装 npm 依赖、不使用构建工具、不加载现成自行车模型。
- 使用米、秒、弧度作为内部单位；遵循 Three.js 的 Y 向上坐标系，X 为车身前后、Z 为车身左右。
- 每个交互组件只有一份注册数据、一份原始变换、一份绝对拆解目标；统一动画循环计算状态。
- 50T 单牙盘、12 片后飞轮，齿数控制传动比和链条绕行半径。换挡为即时运动学演示，不模拟拨链瞬间的弹性、碰撞或负载。
- 轮径约 700 mm，轴距 1120 mm；全部规格、速度、质量均明确标记为演示数据。
- 工程模式的拆解线与标注引用同一份零件注册数据；教学模式调用同一套拆解控制。

## 交付和检查

- `index.html`：完整可运行应用。
- `README.md`：HTTP 启动、操作、功能范围、测试记录和限制。
- 浏览器实测：模块加载、3D 渲染、目录与射线选取、连续拆解、复装、传动互斥、档位与踏频、三种增补模式、视角和响应式布局。
