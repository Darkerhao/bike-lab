# 02. 核心设计理念

整个产品遵循以下五条原则。

## 原则一：模型优先

自行车本身必须是整个页面最重要的视觉内容。

模型的结构、比例、材质和细节优先级高于 UI 装饰。

## 原则二：机械结构真实

每个零件必须具有合理的装配位置、连接关系和运动关系。

不能仅仅让物体看起来像自行车，还必须在机械结构上具有可解释性。

## 原则三：交互具有反馈

任何用户操作都必须产生清晰、即时、可理解的视觉反馈。

禁止存在无响应按钮。

## 原则四：拆解具有逻辑

零件应按照机械系统和实际安装方向拆解，而不是随机向不同方向移动。

## 原则五：视觉克制

科技感来自精细的材质、光照、结构和交互，不是大量发光文字、粒子和网格。

- HTML5
- CSS3
- JavaScript ES Modules

- Three.js 后处理模块

- Vue

# 05. 自行车程序化高精度建模

## 5.1 车型设定

建模对象：

现代高端碳纤维公路自行车。

配置：

- 700C 轮组。
- 碳纤维车架。
- 空气动力学车架造型。
- 弯把。
- 深框轮圈。
- 前后碟刹。
- 双牙盘。
- 多片后飞轮。
- 链条传动。
- 后拨链器。

建议采用真实公路车的几何比例。

参考：

| 项目 | 建议尺寸 |
|---|---:|
| 轮径 | 700mm |
| 轴距 | 1000mm |
| 轮胎宽度 | 28mm |
| 车架立管 | 520mm |
| 座管高度 | 520mm |
| 曲柄长度 | 172.5mm |
| 把立长度 | 100mm |

这些仅作为程序建模的演示尺寸，不代表特定品牌车型。

## 5.2 建模坐标规范

统一建立局部坐标系：

- X：前后方向。
- Y：左右方向。
- Z：垂直方向。

必须定义：

- 前进方向。
- 左右侧。
- 前后轮轴心。
- 五通轴心。
- 头管轴心。
- 座管轴心。

建立统一的尺寸配置对象。

禁止不同建模函数各自随意使用坐标。

所有零件必须根据统一的车架基准点定位。

## 5.3 车架建模

重点要求：

车架不能只是几个细长圆柱体组成。

必须体现现代碳纤维车架的空气动力学外形。

使用：

- 自定义 TubeGeometry。
- CatmullRomCurve3。
- ShapeGeometry。
- ExtrudeGeometry。
- 自定义 BufferGeometry。

根据不同管件调整截面形状。

重点实现：

1. 上管。
2. 下管。
3. 立管。
4. 头管。
5. 后上叉。
6. 后下叉。
7. 五通。
8. 前叉连接节点。
9. 后轮叉端。
10. 车架走线结构。

要求：

- 管件截面不能全部相同。
- 上管具有适度扁平造型。
- 下管具有较明显的空气动力学截面。
- 头管与下管连接自然。
- 五通区域结构清晰。
- 后叉具有真实的连接关系。
- 加入焊接或碳纤维成型连接细节。

车架应具有整体设计感，而不是简单的管材拼接感。

## 5.4 前叉与转向

实现：

- 前叉左右叉腿。
- 前叉肩。
- 头管。
- 转向轴。
- 上下轴承结构。
- 把立。
- 把横。
- 弯把。
- 刹车手变。
- 握把胶带。

弯把必须通过曲线构建，具有合理的弯曲形状。

## 5.5 坐垫系统

实现：

- 人体工程学坐垫。
- 坐垫底座。
- 坐垫导轨。
- 座管。
- 座管夹。
- 固定螺栓。

坐垫不能使用简单的长方体。

使用自定义几何体体现前窄后宽的轮廓。

## 5.6 车轮系统

前后轮独立建模。

每个车轮包含：

- 外胎。
- 胎面。
- 胎壁。
- 轮圈。
- 轮圈侧壁。
- 辐条。
- 辐条帽。
- 花鼓。
- 轴心。
- 端盖。

辐条采用真实交叉布局。

建议通过程序化计算：

- 辐条数量。
- 花鼓法兰位置。
- 轮圈连接点。
- 左右侧辐条。
- 交叉次数。

使用 InstancedMesh 提升性能。

前后轮的辐条应当具有独立的连接关系。

## 5.7 制动系统

前后轮配置独立碟刹。

包含：

- 碟刹盘。
- 碟刹盘固定座。
- 制动孔洞。
- 卡钳。
- 刹车片。
- 固定螺栓。
- 油管。

碟刹盘应具有金属质感和可辨识的机械结构。

## 5.8 传动系统

传动系统是本项目最重要的精细建模区域之一。

牙盘：

- 主体。
- 齿片。
- 齿形。
- 固定螺栓。
- 中心轴。

曲柄：

- 左右曲柄。
- 轴心。
- 固定螺栓。
- 脚踏连接点。

脚踏：

- 轴心。
- 主体。
- 防滑结构。
- 连接部件。

后飞轮：

- 多级齿片。
- 不同齿数。
- 间隔片。
- 塔基。

后拨：

- 固定支架。
- 导向臂。
- 张紧臂。
- 上导轮。
- 下导轮。
- 固定轴。

链条：

不能使用一根圆管代表链条。

必须程序化生成链节。

至少包括：

- 内链板。
- 外链板。
- 链销。
- 滚子。

优先使用 InstancedMesh 或 BufferGeometry 合批。

链条必须形成完整闭合路径。

## 7.3 零件聚焦

提供：

- Focus。
- Zoom to Part。
- Reset Camera。

聚焦当前零件时：

- 相机平滑移动。
- 目标点定位到零件中心。
- 适当调整观察距离。
- 选中零件保持高亮。

## 7.4 零件隔离

点击隔离后：

- 仅保留当前零件。
- 其他部件隐藏或降低透明度。
- 可以查看其真实结构。
- 再次点击恢复完整模型。

隔离状态必须与拆解状态分离管理。

## 7.5 零件隐藏与恢复

支持：

- 隐藏当前零件。
- 显示全部零件。
- 恢复默认显示状态。

隐藏不能破坏零件原始位置。

## 7.6 透视观察模式

增加 X-Ray 模式。

切换后：

- 车架变为半透明。
- 部分外部零件降低透明度。
- 内部机械结构更加清晰。
- 可以调节整体透明度。
- 支持恢复正常材质。

不能通过直接修改整个场景的透明度来实现。

## 7.7 零件工程标注

增加 Engineering Mode。

开启后：

- 每个重要零件显示编号。
- 显示中文名称。
- 显示连接关系。
- 显示空间位置。
- 使用细线连接零件与标签。
- 标签不能大量重叠。

可以根据当前相机距离动态调整标签显示密度。

# 08. 机械爆炸图系统

拆解系统必须具有真实机械装配逻辑。

## 8.1 分层拆解

将自行车分为：

L1：主体车架。

L2：前叉、转向、坐垫。

L3：前后轮组。

L4：前后制动系统。

L5：牙盘、曲柄、脚踏。

L6：链条、飞轮、后拨。

每层可以单独展开。

## 8.2 拆解方向

不同零件采用不同的拆解方向。

示例：

- 前轮：沿前轮轴线向外。
- 后轮：沿后轮轴线向外。
- 牙盘：沿五通轴线向外。
- 曲柄：沿曲柄轴方向分离。
- 飞轮：沿后轮轴线向外。
- 车把：沿转向轴线向上。
- 坐垫：沿座管方向向上。
- 前叉：沿转向轴线向下。
- 刹车卡钳：沿安装方向向外。

不能所有部件都采用相同的 X 轴或 Z 轴偏移。

## 8.3 爆炸图动画

支持：

- 单零件拆解。
- 单个系统拆解。
- 全部拆解。
- 全部组装。
- 连续进度控制。

- 零件平滑展开。
- 保留零件姿态。
- 显示原始安装位置。
- 使用辅助线表示连接关系。

## 8.4 爆炸图进度

提供 0%—100% 控制。

# 09. 真实机械传动仿真

必须建立传动系统的统一运动模型。

不能通过让所有零件同时旋转来伪造传动。

## 9.1 传动系统

曲柄 → 牙盘 → 链条 → 后飞轮 → 后花鼓 → 后轮。

前轮不参与动力传递。

## 9.2 数学关系

定义：

- 前牙盘齿数 Nf。
- 后飞轮齿数 Nr。
- 曲柄角速度 ωc。
- 后轮角速度 ωw。

传动关系：

ωw = ωc × Nf / Nr

链条线速度：

v = ωc × Rf

其中 Rf 为前牙盘节圆半径。

不同档位需要根据实际齿数重新计算。

## 9.3 传动运动

开始传动后：

- 左右曲柄绕五通旋转。
- 两侧脚踏跟随曲柄。
- 牙盘旋转。
- 链条沿闭合路径循环。
- 后飞轮旋转。
- 后花鼓驱动后轮。
- 后轮旋转。
- 前轮保持静止。

链条需要使用曲线采样或圆弧与切线组合构建真实运动路径。

各链节按照固定节距分布。

不能让链条在传动时产生明显跳动或脱离齿盘。

## 9.4 参数控制

提供：

- 开始传动。
- 暂停传动。
- 踏频调节。
- 飞轮档位调节。
- 传动速度调节。

踏频范围：

30—120 RPM。

提供实时数据：

- 当前踏频。
- 当前牙盘齿数。
- 当前飞轮齿数。
- 当前传动比。
- 后轮转速。
- 模拟速度。

明确标注：

SIMULATION DATA / 演示仿真数据。

## 9.5 状态互斥

拆解进度大于 0 时自动暂停传动。

只有完整组装状态才能启动传动。

当用户开始拆解时：

1. 立即暂停传动。
2. 保存当前踏频设置。
3. 进入拆解模式。
4. 禁止继续启动传动。

重新组装后允许再次启动。

# 16. 动画与状态管理

```javascript
const AppState = {
  selectedPartId: null,
```

- 暂停。
- 继续。
- 取消。
- 中途反向。
